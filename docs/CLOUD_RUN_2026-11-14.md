# Combined lunar and discovery deployment — 14 November 2026

The container builds the React frontend from its lockfile and serves it through
nginx. A single internal Python worker handles the existing lunar calculations,
remote terrain lookup and new discovery endpoints. The supervisor waits for API
health before exposing the Cloud Run port and shuts both processes down together.

## Data and credentials

- `data/cloud-release.json` pins the public 41-source Hugging Face release.
- Only its small manifest is installed in the image; elevation blocks remain remote.
- Official NAIF kernels are installed and loaded during the image check.
- Current APOD, NASA Mars raw imagery and NASA library endpoints require no API key.
- Do not create a dummy NASA secret. Any future private credential must be supplied
  through Secret Manager at runtime, never Docker build arguments or source files.
- The Docker and Cloud Build ignore files exclude local environments, credentials,
  dependency folders, build output and local working rasters.

## Build and rollout

- GCP project: `project-70843ff1-1e3d-4725-ba9`.
- Region: `us-central1`.
- Artifact Registry repository: `nasa-site-20261114`.
- `cloudbuild.yaml` builds the image, tests nginx, direct page routes, all 41 source
  records and an actual SPICE calculation, then publishes the checked image.
- Use staging first, then promote the same immutable image digest to production.
- Keep one API worker, minimum instances zero, maximum instances one and low
  concurrency. This bounds work and preserves the process-global SPICE lock.
- The existing project billing/trial remains unchanged. Cloud services and storage
  remain subject to that account's allowances; this is not a free-forever promise.

## Build service-account access

The selected default build account needed explicit permissions. Its source-read
role is scoped to the project's build-source bucket; image-writing is scoped to
this Artifact Registry repository. Log-writing is project-scoped. No owner/editor
role or broad stored GitHub credential is needed by the image or runtime.
